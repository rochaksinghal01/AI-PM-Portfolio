# Ask Kyo — AI CX Intelligence Dashboard

> A prototype of Sentisum's Ask Kyo feature — an AI-powered chatbot embedded across enterprise tools (Teams, Gmail, Meetings) that lets CX teams query customer sentiment, surface anomalies, and get structured insight cards in plain English.

## What It Does

Ask Kyo replaces dashboard navigation with natural language. Users ask "What are customers complaining about this week?" and get structured insight cards with trends, root causes, and suggested next steps — embedded directly in their existing tools.

**Entry points demonstrated:**
- Microsoft Teams (Home + Chat)
- Gmail
- Meeting summaries
- Huddle sessions

## Key Features
- Floating Kyo button across all entry points
- Insight cards with sentiment trends and anomaly flags
- Time range selector (7d / 30d / 90d)
- Call evaluation module — AI scores support calls across quality dimensions
- KPI dashboard with issue charts and data source panel

## Tech Stack
- React + TypeScript + Vite
- Supabase Edge Functions (AI call evaluation)
- Tailwind CSS + shadcn/ui

## Context
Built as a product design prototype while working as AI PM at Sentisum. **Impact: +40% product adoption, measurable reduction in churn risk.**
