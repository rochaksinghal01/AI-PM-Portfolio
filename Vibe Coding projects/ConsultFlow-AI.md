# ConsultFlow AI

**An end-to-end agentic AI system for consulting deck automation.**

Built with TanStack Start, n8n, Gemini 2.5 Flash, Supabase, and Google Slides API. Includes a full eval system that scores every AI output for completeness, groundedness, and quality.
