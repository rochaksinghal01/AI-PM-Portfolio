# SupplierSnap — n8n Workflow

> An agentic procurement intelligence workflow that monitors supplier performance, flags risks, and generates structured supplier scorecards automatically.

## What It Does
- Monitors supplier data (delivery times, quality scores, pricing)
- Flags anomalies and risk signals automatically
- Generates structured supplier scorecards
- Sends alerts when a supplier drops below threshold
- Produces periodic procurement intelligence reports

## How to Import
1. Import `Suppliersnap.json` into your n8n instance
2. Connect to your procurement data source
3. Configure supplier thresholds and alert criteria
4. Set your reporting schedule
5. Activate

## Tech Stack
- n8n · AI for risk scoring and report generation · Scheduled trigger
