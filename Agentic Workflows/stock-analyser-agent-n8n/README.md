# Stock Analyser Agent — n8n Workflow

> An agentic workflow that monitors stocks, runs AI-powered technical and sentiment analysis, and delivers structured investment briefs to Slack or email.

## What It Does
- Pulls real-time and historical stock data
- Runs technical analysis (RSI, MACD, moving averages)
- Scrapes news and social sentiment for the ticker
- Generates a structured analyst brief: thesis, risk factors, price targets
- Delivers to Slack or email on schedule

## How to Import
1. Import `Stock_Analyser_Agent.json` into your n8n instance
2. Add your stock data API credentials
3. Configure your watchlist tickers
4. Set your delivery channel
5. Activate on your preferred schedule

## Tech Stack
- n8n · Stock market API · AI for sentiment and brief generation
